For this question we need the `k` values that appear most often in `nums`. We first build a frequency map `numMap` using `.get(num, 0) + 1`, so each key is a value from the array and each value is its count. To extract the largest `k` counts we use a min-heap of bounded size. We push every `(count, value)` pair onto `temp` — tuples compare element-wise in Python, so the count drives the ordering — and whenever the heap grows beyond `k` entries we pop. Since it is a min-heap the entry that leaves is always the weakest one currently held, so the heap can never contain anything outside the top `k` seen so far. Once every pair has been processed the heap holds exactly the `k` largest counts, and we unpack the tuples into `output` to return just the values.
```python
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        numMap = {}

        for num in nums:
            numMap[num] = numMap.get(num, 0) + 1

        temp = []
        for num, amount in numMap.items():
            heapq.heappush(temp, (amount, num))
            if len(temp) > k:
                heapq.heappop(temp)

        output = []
        for (amount, num) in temp:
            output.append(num)

        return output
```
> Time Complexity : `O(n log k)`
> 
> Space Complexity : `O(n)`
