For this question we need to check whether a string reads the same forwards and backwards once we ignore case and non-alphanumeric characters. Rather than building a cleaned copy of the string, we work on the original in place with two pointers, `left` at the start and `right` at the end. Inside the main loop we first skip over any character that isn't alphanumeric: if `left` points at one we move it forward, and if `right` points at one we move it back, stopping if the pointers meet. Once both pointers sit on valid characters we compare them case-insensitively using `.lower()`. If they differ the string is not a palindrome, so we return `False`. If they match we move both pointers inward and repeat. When the pointers meet or cross, every pair has matched, so we return `True`. A string with no alphanumeric characters at all also returns `True`.
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        while left < right:
            while ((not s[left].isalnum()) or s[left].isspace()) or ((not s[right].isalnum()) or s[right].isspace()):
                if left >= right:
                    break
                if (not s[left].isalnum()) or s[left].isspace():
                    left += 1
                    continue
                if (not s[right].isalnum()) or s[right].isspace():
                    right -= 1
                    continue
            if s[left].lower() != s[right].lower():
                return False
            left += 1
            right -= 1

        return True
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : replace the combined skip loop with two separate inner loops, one for each pointer, each guarded by `left < right`, and drop the `isspace()` checks since `isalnum()` is already false for whitespace.
