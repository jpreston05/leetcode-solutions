For this question we need to find the two positions in a sorted array whose values add up to `target`, returned as 1-indexed positions. Because the array is sorted, we can place one pointer at each end and let the sum tell us which pointer to move. We start with `l` at index `0` and `r` at the last index and add the two values. If the sum is less than `target`, `numbers[l]` is too small to be part of the answer even when paired with the largest remaining value, so we discard it by moving `l` forward. If the sum is greater than `target`, `numbers[r]` is too big even when paired with the smallest remaining value, so we discard it by moving `r` back. Every step permanently eliminates one element, and when the sum matches we return both positions plus one. The problem guarantees exactly one solution, so the loop always finds it before the pointers cross.
```python
class Solution:
    def twoSum(self, numbers: list[int], target: int) -> list[int]:
        l, r = 0, len(numbers)-1
        while l < r:
            s = numbers[l] + numbers[r]
            if s < target:
                l += 1
            elif s > target:
                r -= 1
            else:
                return [l+1, r+1]
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
