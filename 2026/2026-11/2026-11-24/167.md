For this question we need to find the two positions in a sorted array whose values add up to `target`, returned as 1-indexed positions. Because the array is sorted, we can place one pointer at each end and let the sum tell us which pointer to move. We start with `left` at index `0` and `right` at the last index and add the two values. If the sum is less than `target`, `numbers[left]` is too small to be part of the answer even when paired with the largest remaining value, so we discard it by moving `left` forward. If the sum is greater than `target`, `numbers[right]` is too big even when paired with the smallest remaining value, so we discard it by moving `right` back. Every step permanently eliminates one element, and when the sum matches we return both positions plus one. The problem guarantees exactly one solution, so the loop always finds it before the pointers cross.
```python
class Solution:
    def twoSum(self, numbers: list[int], target: int) -> list[int]:
        left, right = 0, len(numbers)-1

        while True:
            sum = numbers[left] + numbers[right]
            if sum < target:
                left += 1
            elif sum > target:
                right -= 1
            else:
                return (left+1, right+1)
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : rename `sum` since it shadows the Python builtin, return a list to match the `list[int]` type hint rather than a tuple, and use `while left < right` as the loop condition so the loop has a real exit instead of relying on the guarantee that a solution exists.
