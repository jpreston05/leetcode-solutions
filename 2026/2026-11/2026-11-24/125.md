For this question we need to check whether a string reads the same forwards and backwards once we ignore case and non-alphanumeric characters. Rather than building a cleaned copy of the string, we work on the original in place with two pointers, `left` at the start and `right` at the end. Each pass of the main loop starts by skipping junk: one inner loop moves `left` forward past any character that isn't alphanumeric, and a second moves `right` back past any such character, each guarded by `left < right` so a pointer can never run off the end. Once both pointers sit on valid characters we compare them case-insensitively using `.lower()`. If they differ the string is not a palindrome, so we return `False`. If they match we move both pointers inward and repeat. When the pointers meet or cross, every pair has matched, so we return `True`. A string with no alphanumeric characters at all also returns `True`, because the skip loops close the gap and the main loop exits.
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s)-1

        while left < right:
            while left < right and not s[left].isalnum():
                left += 1
            while left < right and not s[right].isalnum():
                right -= 1

            if s[left].lower() != s[right].lower():
                return False

            left += 1
            right -= 1

        return True
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
