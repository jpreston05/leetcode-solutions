For this question we need the pair of vertical lines that, together with the x-axis, hold the most water. The area between two lines is the distance between them multiplied by the height of the shorter one. We start with `l` at the first line and `r` at the last, which gives the widest possible container, and compute its area. Then we move one pointer inward. The key insight is which one: the area is limited by the shorter line, so moving the taller line inward can only shrink the width without any chance of raising the limiting height. Moving the shorter line is the only move that might find a taller one and beat the current area. So at each step we move the pointer sitting on the shorter line, tracking the best area seen in `maxArea`. Every step discards one line permanently, so the pointers meet after at most n steps and we return the best area found.
```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        l, r = 0, len(height)-1
        maxArea = -1

        while l < r:
            length = r - l
            h = min(height[l], height[r])
            area = length * h
            if area > maxArea:
                maxArea = area

            if height[l] >= height[r]:
                r -= 1
            elif height[l] < height[r]:
                l += 1

        return maxArea
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : initialise `maxArea` to `0` since areas can't be negative, replace the `if` and `elif` with a plain `if` and `else` because the two conditions cover every case, and use `max(maxArea, area)` instead of the manual comparison.
