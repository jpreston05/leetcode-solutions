For this question two strings are anagrams if they contain exactly the same characters in exactly the same quantities, so we build a frequency map for each string and compare them. We create two empty dictionaries `charMapS` and `charMapT`. Iterating over each character in `s`, we use `.get(char, 0)` to fetch the current count for that character, defaulting to `0` if we haven't seen it before, then add one and store it back. We repeat the same process over `t` to populate `charMapT`. Since dictionary equality in Python compares keys and values rather than insertion order, we can simply return whether the two maps are equal.
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        charMapS = {}
        charMapT = {}

        for char in s:
            charMapS[char] = charMapS.get(char, 0) + 1

        for char in t:
            charMapT[char] = charMapT.get(char, 0) + 1

        return charMapS == charMapT
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : add an early `return False` when `len(s) != len(t)` to skip both passes on mismatched lengths, and be ready to explain the single-dict version that counts up on `s` and down on `t`. The `O(1)` space holds because the problem limits input to lowercase letters, so each map has at most 26 keys.
