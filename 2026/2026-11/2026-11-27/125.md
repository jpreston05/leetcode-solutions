For this question we need to check whether a string reads the same forwards and backwards once we ignore case and non-alphanumeric characters. Rather than building a cleaned copy of the string, we work on the original in place with two pointers, `l` at the start and `r` at the end. Each pass of the main loop starts by skipping junk: one inner loop moves `l` forward past any character that isn't alphanumeric, and a second moves `r` back past any such character, each also checking `l < r` so a pointer can never run off the end. Once both pointers sit on valid characters we compare them case-insensitively using `.lower()`. If they differ the string is not a palindrome, so we return `False`. If they match we move both pointers inward and repeat. When the pointers meet or cross, every pair has matched, so we return `True`. A string with no alphanumeric characters at all also returns `True`, because the skip loops close the gap and the main loop exits.
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s)-1
        while l < r:
            while not s[l].isalnum() and l < r:
                l += 1
            while not s[r].isalnum() and l < r:
                r -= 1
            if s[l].lower() != s[r].lower():
                return False
            l += 1
            r -= 1
        return True
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : put `l < r` first in each skip condition so the bounds check runs before the index.
