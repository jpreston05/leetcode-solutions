For this question we need to find the two indices whose values sum to `target`. Rather than searching for pairs directly, we build a dictionary `numMap` mapping each value we have already seen to the index it appeared at. Iterating over `nums` by index, we first calculate the `remainder` we would need to reach `target` from the current value. If that remainder is already a key in `numMap` then we have seen its partner earlier in the array, so we return the two indices. Otherwise we record the current value and index in `numMap` and move on. Because we check the map before inserting the current element, the current element is never in the map when we look, so it is impossible to pair a value with itself.
```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        numMap = {}
        for i in range(len(nums)):
            remainder = target-nums[i]
            if numMap.get(remainder) is not None:
                return [i, numMap[remainder]]
            else:
                numMap[nums[i]] = i
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`

> Improvement for next time : use `remainder in numMap` instead of `.get(remainder) is not None` for a single lookup, loop with `enumerate(nums)` instead of `range(len(nums))`, return the earlier index first (`[numMap[remainder], i]`), and add a final `return []` so the function never falls off the end and returns `None`.
