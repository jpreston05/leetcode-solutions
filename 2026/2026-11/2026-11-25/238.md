For this question we need each `answer[i]` to hold the product of every element in `nums` except `nums[i]`, without using division. The insight is that the answer for any index is the product of everything to its left multiplied by the product of everything to its right, so we compute those two running products in two passes and never need the element itself.

We start with `answer` filled with `1`s. In the first pass we walk left to right carrying a running product `left` of everything seen so far. Before folding `nums[i]` into `left`, we write the current `left` into `answer[i]`, so at that moment `answer[i]` holds the product of everything strictly to the left of `i`. In the second pass we walk right to left carrying a running product `right` and multiply it into `answer[i]`, which layers the product of everything strictly to the right on top of the prefix already stored there. The two passes together give every index its full answer.
```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        left, right = 1, 1
        answer = [1]*len(nums)

        for i in range(len(nums)):
            answer[i] = left
            left *= nums[i]

        for i in range(len(nums)-1, -1, -1):
            answer[i] *= right
            right *= nums[i]

        return answer
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)` extra space, not counting the output array
