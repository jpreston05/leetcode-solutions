For this question we need every unique triplet in `nums` that sums to zero. We first sort the array, which lets us reuse the converging two-pointer idea from Two Sum II. We fix one element at index `i` with an outer loop, then look for a pair to its right that sums to `-nums[i]`, placing `left` at `i + 1` and `right` at the end. Two checks at the top of the outer loop save work: if `nums[i]` equals the previous value we already processed we skip it, since it would only rediscover the same triplets, and if `nums[i]` is positive we break, since the array is sorted and nothing after it can sum to zero. Inside, if the three values sum to zero we record the triplet, move `left` forward, and keep moving it past any value equal to the one before it so the same pair can't be found twice. If the sum is below zero we move `left` forward to make it larger, and if it is above zero we move `right` back to make it smaller. Because both the outer value and the left value are deduplicated, every triplet is found exactly once and we can collect them straight into a list.
```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:

        output = []

        nums = sorted(nums)
        prevNumsI = None

        for i in range(len(nums)-2):
            if prevNumsI == nums[i]:
                continue
            if nums[i] > 0:
                break
            left, right = i+1, len(nums)-1
            while left < right:
                if nums[left] + nums[right] + nums[i] == 0:
                    output.append((nums[left], nums[right], nums[i]))
                    left += 1
                    while nums[left-1] == nums[left] and left < right:
                        left += 1
                elif nums[left] + nums[right] + nums[i] < 0:
                    left += 1
                else:
                    right -= 1

            prevNumsI = nums[i]

        return output
```
> Time Complexity : `O(n²)`
> 
> Space Complexity : `O(n)` for the sorted copy, not counting the output

> Improvement for next time : append each triplet as a list (`[nums[i], nums[left], nums[right]]`) to match the `list[list[int]]` type hint rather than a tuple, store the three-way sum in a variable instead of recomputing it in each branch, and put `left < right` first in the skip condition so the bounds check runs before the index.
