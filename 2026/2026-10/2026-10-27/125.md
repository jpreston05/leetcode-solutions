For this question we need to check whether a string reads the same forwards and backwards once we ignore case and non-alphanumeric characters. We first clean the input in one line: `filter(str.isalnum, s)` keeps only letters and digits, `"".join()` stitches them back into a string, and `.lower()` normalises the case. We then place two pointers, `left` at the start and `right` at the end, and walk them inward comparing the characters they point at. If the characters ever differ the string is not a palindrome, so we return `False`. If they match we move both pointers inward and repeat. The loop ends successfully in one of two ways: for an odd-length string the pointers meet on the middle character (`left == right`), and for an even-length string they become adjacent after a matching pair (`left + 1 == right`). An empty cleaned string is handled by clamping `right` to `0` so that it immediately meets `left`.
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        s = "".join(filter(str.isalnum, s)).lower()
        left, right = 0, len(s) - 1

        if right < 0:
            right = 0

        while True:
            if left == right:
                return True

            if s[left] == s[right]:
                if (left+1) == right:
                    return True

                left += 1
                right -= 1
                continue
            else:
                return False
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`

> Improvement for next time : use `while left < right` as the loop condition to remove the extra exit checks and the empty-string clamp, and skip non-alphanumeric characters with the pointers instead of building a new string to bring space down to `O(1)`.
