For this question we need to find the two positions in a sorted array whose values add up to `target`, returned as 1-indexed positions. We start with `left` at index `0` and `right` at index `1` and check the sum of the two values. If it matches `target` we return both positions plus one. If it doesn't, we move `right` forward past every element equal to the current right value, since an identical value would give the same sum. Once `right` runs off the end of the array, we move `left` forward past every element equal to the current left value and reset `right` to just after it. This enumerates candidate pairs while skipping repeated values, and because the problem guarantees exactly one solution the loop always finds it before running out of bounds.
```python
class Solution:
    def twoSum(self, numbers: list[int], target: int) -> list[int]:
        left, right = 0, 1
        while True:
            curLeft = numbers[left]
            curRight = numbers[right]
            
            twoSum = numbers[left] + numbers[right]
            if twoSum != target:
                while (right < len(numbers)) and (numbers[right] == curRight):
                    right += 1
                if right == len(numbers):
                    while (numbers[left] == curLeft):
                        left += 1
                        right = left + 1
            else:
                return [left+1, right+1]
```
> Time Complexity : `O(n²)`
> 
> Space Complexity : `O(1)`

> Improvement for next time : start `left` at the beginning and `right` at the end, then use the sorted order to move one pointer per step (move `left` up if the sum is too small, `right` down if it is too big), which brings time down to `O(n)` with the same `O(1)` space.
