For this question we need to check whether a partially filled 9×9 board breaks any Sudoku rule: no digit may repeat within a row, a column, or a 3×3 box. Rather than storing seen digits in sets, we pack each grouping's seen-digits into a single integer and use its bits as nine on/off flags — one bit per digit.

We keep three arrays of nine integers each: `rows`, `cols`, and `boxes`, all starting at `0` (nothing seen). Iterating over every cell `(i, j)`, we skip empty cells, then turn the digit into a bit position with `n = int(board[i][j]) - 1` and build a single-bit mask `d = 1 << n` — an integer with exactly one `1`, at position `n`. The box the cell belongs to is `(i // 3) * 3 + (j // 3)`, which collapses the two-dimensional box position into a single index from `0` to `8`.

To check for a duplicate we AND the mask against each of the three relevant integers: `rows[i] & d` is non-zero only if that digit's bit is already set in row `i`, and likewise for the column and box. If any of the three is non-zero the digit has been seen in that grouping, so we return `False`. Otherwise we record the digit by OR-ing the mask into all three integers with `|=`, which turns that bit on while leaving the others untouched. The array index isolates *which* grouping and the bit position isolates *which* digit, so the three records never interfere. Surviving every cell means the board is valid.
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rows = [0]*9
        cols = [0]*9
        boxes = [0]*9

        for i in range(9):
            for j in range(9):
                if board[i][j] == ".":
                    continue
                n = int(board[i][j]) - 1
                d = 1 << n
                box = (i//3)*3 + (j//3)

                if rows[i] & d or cols[j] & d or boxes[box] & d:
                    return False

                rows[i] |= d
                cols[j] |= d
                boxes[box] |= d

        return True
```
> Time Complexity : `O(1)` for the fixed 9×9 board — `O(n²)` generalised to an n×n grid
> 
> Space Complexity : `O(1)` for the fixed board — `O(n)` generalised, one integer per row, column, and box
