For this question we need to bucket together every string that is an anagram of another. The key insight is that any two anagrams produce the same result once their characters are sorted, so that sorted form can act as a shared identifier. We create a dictionary `anagramMap` where each key is that identifier and each value is a list of the original words that produced it. Iterating over `strs`, we sort the characters of the current word and `''.join()` them back into a compact string to use as the key, then use `.setdefault(key, [])` to fetch the existing bucket for that key — creating an empty list in place if this is the first word with that signature — and append the word to it. Since `setdefault` returns the list itself, we mutate the bucket directly rather than rebuilding it. Once every word has been placed, the groups we want are exactly the values of the dictionary, so we collect them into `output` and return it.
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagramMap = {}

        for s in strs:
            anagramMap.setdefault(''.join(sorted(s)), []).append(s)

        output = []
        for i in anagramMap.values():
            output.append(i)

        return output
```
> Time Complexity : `O(n * k log k)`
> 
> Space Complexity : `O(n * k)`
