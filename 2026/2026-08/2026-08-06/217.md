For this question we take advantage of the fact that a set cannot hold duplicate values. Passing `nums` into `set()` strips out any repeats, so if the resulting set is shorter than the original array then at least one duplicate was removed. We compare the two lengths directly and return whether they differ — `True` if a duplicate was dropped, `False` if every element was unique.
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return len(set(nums)) != len(nums)
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
