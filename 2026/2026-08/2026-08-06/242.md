For this question two strings are anagrams if they contain exactly the same characters in exactly the same quantities. Sorting rearranges each string's characters into a canonical order, so two anagrams always produce identical sorted sequences. We sort both `s` and `t` and simply compare the results — if they match the strings are anagrams, otherwise they are not.
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return sorted(t) == sorted(s)
```
> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
