For this question we need to check whether a partially filled 9×9 board breaks any Sudoku rule: no digit may repeat within a row, a column, or a 3×3 box. We track what we have already seen in each of those three groupings using three dictionaries — `rowMap`, `colMap`, and `boxMap` — each mapping a group index to the list of digits placed in it so far.

Iterating over every cell `(i, j)`, we first identify which 3×3 box it belongs to. The formula `(i // 3) * 3 + (j // 3)` collapses the two-dimensional box position into a single index from `0` to `8`: integer-dividing the row and column by 3 gives the box's row-band and column-band, and combining them numbers the boxes left-to-right, top-to-bottom. For each cell we check whether its digit already appears in the corresponding row, column, or box — ignoring `"."`, which marks an empty cell — and return `False` the moment we find a clash. Otherwise we record the digit in all three maps and continue. Surviving every cell means the board is valid.
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        rowMap = {}
        colMap = {}
        boxMap = {}

        for i in range(len(board)):
            for j in range(len(board[i])):
                num = board[i][j]
                box = (i // 3) * 3 + (j // 3)
                if (num in rowMap.get(i, []) or num in colMap.get(j, []) or num in boxMap.get(box, [])) and num != ".":
                    return False
                rowMap.setdefault(i, []).append(num)
                colMap.setdefault(j, []).append(num)
                boxMap.setdefault(box, []).append(num)

        return True
```
> Time Complexity : `O(1)`
> 
> Space Complexity : `O(1)`
