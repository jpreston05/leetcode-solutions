For this question we need to bucket together every string that is an anagram of another. The key insight is that any two anagrams produce an identical string once their characters are sorted, so the sorted form can act as a shared identifier. We create a dictionary `anagramMap` where each key is that sorted form and each value is a list of the original words that produced it. Iterating over `strs`, we sort the characters of the current word and `''.join()` them back into a string to use as `key`, then use `.get(key, [])` to fetch the existing bucket for that key — defaulting to an empty list if this is the first word we have seen with that signature — and add the current word to it. Once every word has been placed, the groups we want are simply the values of the dictionary, so we collect them into `group` and return it.
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagramMap = {}
        group = []

        for i in range(len(strs)):
            key = ''.join(sorted(strs[i]))
            anagramMap[key] = anagramMap.get(key, []) + [strs[i]]

        for value in anagramMap.values():
            group.append(value)

        return group
```
> Time Complexity : `O(n * k log k)`
> 
> Space Complexity : `O(n * k)`
