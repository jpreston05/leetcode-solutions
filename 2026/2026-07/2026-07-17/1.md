For this question we need to find the two indices whose values sum to `target`. We build a dictionary `numMap` that maps each value in `nums` to a list of every index it appears at — a list rather than a single index so that duplicate values don't overwrite each other. We iterate over `nums` by index, creating an empty list for a value the first time we see it, then appending the current index. On the second pass we iterate over the values in `nums` and check whether `target - num` exists in the map and that both index lists still have entries. There is one edge case: if `num` and `target - num` are the same value, we would be reusing a single element twice, so if that value only appears once we `continue` past it. Otherwise we pop an index from each list and return the pair. If nothing matches we return an empty list.
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:

        numMap = {}

        for i in range(len(nums)):
            if nums[i] not in numMap:
                numMap[nums[i]] = []
            numMap[nums[i]].append(i)

        for num in nums:
            if (target - num) in numMap and len(numMap[num]) > 0 and len(numMap[target - num]) > 0:
                if (num == target - num) and len(numMap[num]) == 1:
                    continue
                return ((numMap[num]).pop(), (numMap[target - num]).pop())

        return []
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
