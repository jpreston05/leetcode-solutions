For this question we take advantage of the fact that a set cannot hold duplicate values. We pass the input array `nums` into `set()` to create `setArray`, which strips out any repeated values. If the length of `setArray` matches the length of `nums` then nothing was stripped out, meaning every element was unique, so we return `False`. Otherwise at least one duplicate was removed and we return `True`.
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        setArray = set(nums)
        if len(setArray) == len(nums):
            return False
        return True
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
