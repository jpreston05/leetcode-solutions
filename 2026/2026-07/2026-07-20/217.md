For this question we take advantage of the fact that a set cannot hold duplicate values. We pass the input array `nums` into `set()`, which strips out any repeated values, and compare its length against the length of `nums`. If the two lengths match then nothing was stripped out, meaning every element was unique, so we return `False`. Otherwise at least one duplicate was removed and we return `True`.
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return False if len(set(nums)) == len(nums) else True
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
