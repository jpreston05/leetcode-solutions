For this question we need to bucket together every string that is an anagram of another. The key insight is that any two anagrams produce the same result once their characters are sorted, so that sorted form can act as a shared identifier. We create a dictionary `groupMap` where each key is that identifier and each value is a list of the original words that produced it. Iterating over `strs`, we sort the characters of the current word and use `.setdefault(key, [])` to fetch the existing bucket for that key — creating an empty list in place if this is the first word with that signature — then append the word to it. Since `setdefault` returns the list itself, we mutate the bucket directly rather than rebuilding it. Once every word has been placed, the groups we want are the values of the dictionary, so we collect them into `output` and return it.
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groupMap = {}
        output = []

        for s in strs:
            groupMap.setdefault(str(sorted(s)), []).append(s)

        for value in groupMap.values():
            output.append(value)

        return output
```
> Time Complexity : `O(n * k log k)`
> 
> Space Complexity : `O(n * k)`
