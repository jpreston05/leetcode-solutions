For this question two strings are anagrams if they contain exactly the same characters in exactly the same quantities, so we build a frequency map for each string and compare them. We create two empty dictionaries `sMap` and `tMap`. Iterating over each character in `s`, we use `.get(char, 0)` to fetch the current count for that character, defaulting to `0` if we haven't seen it before, then add one and store it back. We repeat the same process over `t` to populate `tMap`. Since dictionary equality in Python compares keys and values rather than insertion order, we can simply return whether the two maps are equal.
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        sMap = {}
        tMap = {}

        for char in s:
            sMap[char] = sMap.get(char, 0) + 1

        for char in t:
            tMap[char] = tMap.get(char, 0) + 1

        return True if sMap == tMap else False
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
