For this question we need the `k` values that appear most often in `nums`. Every approach below starts the same way — we build a frequency map `numMap` using `.get(num, 0) + 1`, so each key is a value from the array and each value is its count. The difference between the three is how we extract the largest `k` counts from that map.

### Approach 1 — repeated linear scan

The most direct approach is to find the maximum `k` times. We loop `k` times, and on each pass we walk the entire map tracking the highest count seen in `maxValue` and its corresponding key in `maxItem`. Once we have the maximum for that pass we append it to `topK` and set its count to `0` in the map, which excludes it from every later pass without needing to delete it.
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        numMap = {}
        topK = []

        for num in nums:
            numMap[num] = numMap.get(num, 0) + 1

        for i in range(k):
            maxValue = 0
            maxItem = 0
            for item, value in numMap.items():
                if value > maxValue:
                    maxValue = value
                    maxItem = item
            numMap[maxItem] = 0
            topK.append(maxItem)

        return topK
```
> Time Complexity : `O(n * k)`
> 
> Space Complexity : `O(n)`

### Approach 2 — maintain a sorted list of size k

Instead of scanning the map `k` times we can walk it once and keep a running list of the best `k` candidates as `(count, value)` tuples. While `topK` holds fewer than `k` entries we simply append. Once it is full, we sort it ascending so the weakest candidate sits at index `0`, and if the current count beats that weakest entry we overwrite it. At the end we unpack the tuples to return just the values.
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        numMap = {}
        topK = []

        for num in nums:
            numMap[num] = numMap.get(num, 0) + 1

        for item, value in numMap.items():
            if len(topK) < k:
                topK.append((value, item))
            else:
                topK = sorted(topK)
                if topK[0][0] < value:
                    topK[0] = (value, item)

        output = []
        for (value, item) in topK:
            output.append(item)

        return output
```
> Time Complexity : `O(n * k log k)`
> 
> Space Complexity : `O(n)`

### Approach 3 — min-heap of size k

Approach 2 sorts the entire candidate list just to find its smallest element, which is far more work than we need. A min-heap gives us that smallest element at index `0` for free. We push every `(count, value)` pair onto the heap, and whenever the heap grows beyond `k` entries we pop — since it is a min-heap, the entry that leaves is always the weakest one currently held. After processing every pair the heap contains exactly the `k` largest counts, and we unpack the tuples to return the values.
```python
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        numMap = {}
        topK = []

        for num in nums:
            numMap[num] = numMap.get(num, 0) + 1

        for item, value in numMap.items():
            heapq.heappush(topK, (value, item))
            if len(topK) > k:
                heapq.heappop(topK)

        output = []
        for (value, item) in topK:
            output.append(item)

        return output
```
> Time Complexity : `O(n log k)`
> 
> Space Complexity : `O(n)`
