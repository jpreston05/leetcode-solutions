For this question we need to serialise a list of strings into a single string and recover the original list from it. The problem is that any character we pick as a separator could legitimately appear inside one of the strings, so a separator alone is never enough. We solve this by length-prefixing: before each string we write its length, followed by a `#` delimiter, followed by the string itself. The delimiter only marks where the digits of the length stop.

In `encode` we iterate over `strs` and build up the output as `str(len(s)) + "#" + s` for each string.

In `decode` we walk the encoded string with a pointer `i`. At each step `i` sits at the start of a length prefix, so we read characters into `strLen` until we hit the `#` delimiter, then step over the delimiter and convert the digits to an integer. Knowing exactly how many characters the next string occupies, we slice it directly with `s[i : i + strLen]`, jump `i` forward by that length to land on the next prefix, and append the recovered string. This is what makes the encoding safe — we never scan the content looking for a delimiter, so a `#` appearing inside one of the original strings is consumed as part of the slice and never mistaken for a separator.
```python
class Solution:

    def encode(self, strs: List[str]) -> str:
        output = ""

        for s in strs:
            output += str(len(s)) + "#" + s

        return output

    def decode(self, s: str) -> List[str]:
        output = []

        i = 0

        while i < len(s):
            strLen = ""
            while s[i] != "#":
                strLen += s[i]
                i += 1
            i += 1
            strLen = int(strLen)

            output.append(s[i : i + strLen])

            i += strLen

        return output
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
