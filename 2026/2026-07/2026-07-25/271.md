For this question we need to serialise a list of strings into a single string and recover the original list from it. The problem is that any character we pick as a separator could legitimately appear inside one of the strings, so a separator alone is never enough. We solve this by length-prefixing: before each string we write its length, followed by a `#` delimiter, followed by the string itself. The delimiter is only there to mark where the digits of the length stop.

In `encode` we iterate over `strs`, format each string as `f"{len(s)}#{s}"`, collect the pieces in a list and `"".join()` them into a single output string.

In `decode` we walk the encoded string with a pointer `i`. At each step `i` sits at the start of a length prefix, so we read characters into `length` until we hit the `#` delimiter, then step over the delimiter and convert the collected digits to an integer. Knowing exactly how many characters the next string occupies, we slice it directly with `s[i : i + length]`, jump `i` forward by that length to land on the next prefix, and append the recovered string to the output. This is what makes the encoding safe — we never scan the content looking for a delimiter, so a `#` appearing inside one of the original strings is consumed as part of the slice and never mistaken for a separator.
```python
class Solution:

    def encode(self, strs: List[str]) -> str:
        output = []
        for s in strs:
            output.append(f"{len(s)}#{s}")
        return "".join(output)


    def decode(self, s: str) -> List[str]:
        output = []
        i = 0
        while i < len(s):
            length = []
            while s[i] != "#":
                length.append(s[i])
                i += 1
            i += 1
            length = int("".join(length))
            string = s[i : i + length]
            i += length
            output.append(string)
        return output
```
> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
