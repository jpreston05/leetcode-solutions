For this question we need the `k` values that appear most often in `nums`. We first build a frequency map `countMap` using `.get(num, 0) + 1`, so each key is a value from the array and each value is its count. To extract the largest `k` counts we use a min-heap of bounded size. We push every `(count, value)` pair onto `topK` — tuples compare element-wise in Python, so the count drives the ordering — and whenever the heap grows beyond `k` entries we pop. Since it is a min-heap the entry that leaves is always the weakest one currently held, so the heap can never contain anything outside the top `k` seen so far. Once every pair has been processed the heap holds exactly the `k` largest counts, and we unpack the tuples into `output` to return just the values.
```python
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        countMap = {}
        topK = []

        for num in nums:
            countMap[num] = countMap.get(num, 0) + 1

        for key, value in countMap.items():
            heapq.heappush(topK, (value, key))
            if len(topK) > k:
                heapq.heappop(topK)

        output = []
        for key, value in topK:
            output.append(value)

        return output
```
> Time Complexity : `O(n log k)`
> 
> Space Complexity : `O(n)`
